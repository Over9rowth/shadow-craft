# 影子剪纸机（shadow-craft）

想要墙上出现某个形状的影子？它告诉你该剪一张**多大**的纸、剪成什么形状。

单光源、平行墙面的简化模型：灯在纸后、纸在墙前，纸上挖出的孔把光投到墙上。
只要知道「灯到墙」和「纸到墙」两个距离，纸上的形状就是墙上影子的**同形放大**，
比例固定为 `d/h`——工具把这个比例算给你，并输出 1:1 的 A4 分页打印模板。

## 它是什么

- **三步向导**：① 选影子形状（6 个内置形状，或导入照片做阈值剪影） → ② 摆灯和纸（三个滑块，实时侧视图 + 纸的实际尺寸读数） → ③ 导出 A4 打印模板 PDF / 纸样 PNG。
- **真实几何**：`P = L + (d/h)(S − L)`，位似中心是光源的水平投影点。改动任一距离，纸上尺寸立刻跟着变。
- **真实尺寸打印**：模板按 150 dpi 出图，A4 可打印区 18 × 26.7 cm 分页，页边带拼接对齐记号；打印后按记号拼起来，剪下来就是 1:1 的纸样。

## 它不是什么

- **不是精确的光学仿真**：点光源、硬边缘、忽略半影。真实灯泡有大小，边缘一定会有过渡带，离墙越远越糊。
- **不处理多光源、不处理斜射**：灯必须正对墙面，纸必须与墙平行。斜着打光，形状会被拉斜，本工具算不了。
- **不保证剪完就是那个影子**：纸的厚度、剪刀的误差、灯的实际位置都会让结果偏离。它给的是几何上正确的起点。
- **不上传任何东西**：没有网络请求，照片只在本机内存里处理。

## 安装与使用

- 安装：运行 `交付物` 里的 `ShadowCraft-<版本>-Setup.exe`（未签名，系统如提示请选择"仍要运行"）。安装后从开始菜单打开「影子剪纸机」。
- 卸载：Windows 设置 → 应用 → 已安装的应用 → 影子剪纸机 → 卸载。
- 第一次用：先在「选影子」里挑一个内置形状，直接进第三步打印一张试贴；确认尺寸对得上，再换自己的照片。

## 开发命令

```bash
npm install        # 安装依赖
npm test           # 几何引擎单元测试（node --test）
npm run build      # 先 tsc --noEmit 类型检查，再用 esbuild 构建到 dist/
npm run typecheck  # 只跑类型检查
npm run smoke      # 真实启动 Electron：挂载自检 + 真实导出两份 PDF 并校验
npm run dev        # 构建 + 打开应用
npm run manual     # 生成《用户使用说明书.pdf》到 交付物/
npm run make       # electron-forge 打包（中文路径需先 subst，见 docs/implementation-status.md）
```

## 架构

- `src/domain/geometry.cjs`：位似几何（纯函数，可被 node 直接测试），`geometry.d.cts` 是对应类型声明。
- `src/renderer/App.tsx`：React 三步向导；影子掩码、纸样绘制、瓦片分页都在渲染进程。
- `src/main/index.ts`：主进程（窗口、PDF 导出、PNG 另存、`--smoke` 冒烟校验、Squirrel 快捷方式自管理）。
- `src/preload/index.ts`：contextIsolation 下的窄接口。
- `resources/manual.html`：内置图文说明书，经主进程 `printToPDF` 导出。

## 已知限制

- 只有单光源、硬阴影；不模拟半影与多次反射。
- 照片剪影用亮度阈值，背景复杂或主体与背景亮度接近时需要手动调阈值与反相。
- 纸样按 A4 可打印区分页，超出部分自动拆页并带拼接记号；拼接误差由手工对齐决定。
- Windows 安装包未做代码签名。
